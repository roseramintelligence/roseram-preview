## Mirror software responsibly

Clone the relevant public source repository and preserve its complete LICENSE, attribution and upstream notices. Review the latest commit and release status before making a public mirror. Set the mirror description to identify Roseram and link to the original repository so users can find the maintained source. Do not describe a mirror as an additional official distribution until its ownership and update process are established.

GitLab and Bitbucket publication is pending an authenticated account connection. SourceForge, package registries and application marketplaces require their own project ownership and release review; this file does not claim those listings exist.

## Contextual product links

## Release boundaries

Only publish the selected public package. Production repositories contain private material and are not covered by this public distribution inventory. Never add credentials, account data, commercial manuscripts or internal dependency artifacts to a mirror.
